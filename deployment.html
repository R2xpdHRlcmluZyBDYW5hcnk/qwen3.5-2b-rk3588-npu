1. 部署结果与范围

在 RK3588S、8GB 内存、ARM64 Linux 上完成 Qwen3.5-2B 的文本与图片问答。官方 BF16 来源权重经 Rockchip 工具转换为板端 FP16 格式；语言和视觉均设置不量化，没有使用 INT8/INT4。原始 Safetensors 不能直接交给该 NPU 运行。

语言与视觉由 Rockchip NPU 运行；图像预处理、分词、采样和接口等工作仍会使用 CPU。服务使用现成 VLM 实现及范围有限的生命周期/管理接口改动，不提供 Agent 或工具执行能力。

客户端通过完整 messages 传递所需历史；开启新对话时在客户端清空历史。请求内生成仍使用 KV 来避免重复计算，清理发生在请求结束后。模型权重和运行时预分配缓冲继续常驻，清缓存不会使进程内存降至零。

2. 先检查环境与依赖许可

目标板需要可工作的官方兼容 RKNPU 驱动。本次验证内核为 6.1.115-vendor-rk35xx、驱动 0.9.8。不要根据芯片名称就假定任意主线内核可直接使用该运行库；换内核不包含在安装脚本中。

uname -m
uname -r
cat /sys/kernel/debug/rknpu/version
ls -l /dev/dri/card* /dev/dri/renderD*
getent group render video
free -h
swapon --show
ss -lntH 'sport = :18080'

检查应为 aarch64，驱动可读，DRM 设备属于相应组；端口没有被其他实例占用。保留系统及其他业务内存余量，本次系统已有 swap，未验证完全关闭 swap 的长期运行行为。驱动使用 DRM card 节点，因此只添加 render 组不足；无需把 NPU 进程改成 root。

转换放在 x86_64 Linux/WSL，板端只安装和运行。WSL 中先安装基础依赖：

sudo apt-get update
sudo apt-get install --no-install-recommends git curl ca-certificates libgl1 libglib2.0-0t64

模型与 SDK 从原始发行方下载并遵循各自许可证。第三方 VLM 服务未声明许可证，本资料不分发其源码，也不把它重新许可为 MIT。具体边界见本文许可章节。

3. 在电脑 WSL 转换官方模型

将本文附带的 scripts 目录放入 WSL 可访问的位置；它不应与模型产物目录混放。以下在包含 scripts 的复现资料根目录执行：

export BUILD_DIR=/var/tmp/qwen3.5-2b-build
bash scripts/convert_wsl.sh

脚本安装两个独立 Python 环境：语言环境使用 torch 2.6.0 CPU、transformers 5.8.0 和 RKLLM 1.3.1；视觉编译环境使用 torch 2.4.0 CPU、RKNN Toolkit2 2.5.0。Qwen3.5 视觉 ONNX 在语言环境导出，随后在视觉环境编译。无需在目标板转换，也不依赖电脑 GPU。

下载来自固定 Qwen 官方 revision，校验原权重 SHA-256。语言设置 do_quantization=False、optimization_level=0、3 个 NPU 核心、导出上下文 4096；官方视觉导出脚本也不量化。转换完成后检查：

cd /var/tmp/qwen3.5-2b-build/outputs
sha256sum -c SHA256SUMS
cat qwen35-conversion.json

输出为 qwen3.5-2b_fp16_rk3588.rkllm、qwen3.5_vision_rk3588.rknn 和校验清单。模型只保存在 WSL 构建目录与目标板，不放入复现资料或 Git 仓库。本次产物校验值见验证记录；重新构建时以本次生成的清单传输核验，并重新进行板端验收。

4. 传输并安装目标板服务

下面是 Windows PowerShell 示例。将 BOARD_HOST 设为自己已配置好 SSH 的目标板主机名；路径使用环境变量和占位值。

$env:BOARD_HOST = "your-board-host"
$ReproRoot = Join-Path $env:USERPROFILE "OneDrive\Manual\Linux\LLM\Qwen3.5-2B"
$Artifacts = "\\wsl.localhost\Debian\var\tmp\qwen3.5-2b-build\outputs"

scp "$Artifacts\qwen3.5-2b_fp16_rk3588.rkllm" "$Artifacts\qwen3.5_vision_rk3588.rknn" "$Artifacts\SHA256SUMS" "root@${env:BOARD_HOST}:/opt/qwen3.5-2b/models/"
scp -r "$ReproRoot\scripts" "root@${env:BOARD_HOST}:/var/tmp/qwen35-repro/"
ssh "root@$env:BOARD_HOST" "bash /var/tmp/qwen35-repro/scripts/install_board.sh"

如果 WSL 发行版不是 Debian，修改传输路径中的发行版名称。安装脚本核验模型，停止已有实例，安装独立 Python、固定运行库及服务端，再按源码 SHA 校验并应用本地改动。它检查现有全局运行库链接，遇到其他部署的库会停止；应先确认归属再调整，不能盲目覆盖共享库。

首次加载或存储繁忙时初始化可能持续数分钟；以 /health 正常响应和日志的 Application startup complete 为就绪依据，systemd 的 active 不能单独代表模型已加载成功。安装脚本启动服务，验收后再启用开机启动：

systemctl show qwen3.5-2b.service -p User -p DynamicUser -p NRestarts -p MemoryCurrent -p MemoryPeak
ps -p "$(systemctl show qwen3.5-2b.service -p MainPID --value)" -o pid,uid,comm
curl --fail --unix-socket /run/qwen3.5-2b/inference.sock http://localhost/health
# 完成下面的功能验收后执行：
systemctl enable qwen3.5-2b.service qwen3.5-2b-socket.socket

确认 DynamicUser=yes、UID 非 0、进程名正确、NRestarts 没有异常增加。实际已部署实例已完成验证并启用自启动。

5. 本地问答、中断与清缓存

接口是 Unix Socket 上的 HTTP，兼容常用的 OpenAI Chat Completions 请求格式，不是 gRPC。无需开启外部监听。Socket 为 root 可访问的 0600，服务自身以动态用户运行；调用者权限与模型进程权限是两件事。

文本问答

curl --fail-with-body --unix-socket /run/qwen3.5-2b/inference.sock   http://localhost/v1/chat/completions   -H 'Content-Type: application/json'   -d '{"model":"Qwen3.5-2B","messages":[{"role":"user","content":"请简要介绍太阳系。"}],"enable_thinking":false,"max_tokens":128,"stream":false}'

流式输出把 stream 改为 true，并给 curl 添加 -N。每次显式传入 max_tokens 和 enable_thinking；需要思考时设为 true。上游的 token 用量是估算值，而且含原生生成额度扩展逻辑；不能把该接口当作完整的 OpenAI 服务实现。

思考与增量正文

固定版本已经支持 enable_thinking:true 和 stream:true，无需改动服务单元。SSE 中 delta.content 为正文，delta.reasoning_content 为私有推理频道。面向用户的客户端丢弃私有频道，可显示证据读取、查询状态和简短依据摘要作为分析进度。

python scripts/stream_chat.py '请简要说明如何核对一条网络连接的可见元数据。'
python -B scripts/test_stream_chat.py

该标准库客户端通过本地 Unix Socket 逐段输出正文，默认开启思考，不保存会话。Ctrl+C 关闭当前流并触发已有的断线取消，不调用全局中断接口。

服务单元使用 --timeout 0 关闭流式无输出超时。生成流持续到完成、模型报错或客户端断开，参考客户端只限制连接建立时间。上下文仍为 2048，原生生成额度由服务根据 max_tokens 扩展，较长思考可能留下较少正文空间。非关闭的 reasoning_effort 统一开启思考，当前版本没有 low / medium 档位差异或云端 thinking_budget。下文性能记录仍对应关闭思考的验收请求。

参数核对于 2026-11-05，来源为 Qwen 官方模型卡、阿里云接口说明及本教程固定版本的服务源码；云端模型的档位范围不等同于本地实现。

中断与清缓存

# 在另一个终端中断当前推理：
curl --fail-with-body --unix-socket /run/qwen3.5-2b/inference.sock   -X POST http://localhost/v1/abort
# 等待 active_requests=0，last_cleared_kv_positions=0：
curl --fail --unix-socket /run/qwen3.5-2b/inference.sock http://localhost/health
# 空闲时可显式清 KV，通常无需调用，因为每次请求结束已自动清理：
curl --fail-with-body --unix-socket /run/qwen3.5-2b/inference.sock   -X POST http://localhost/v1/cache/clear

/v1/abort 通过官方 rkllm_abort 中断当前请求；若返回 cancelling，应继续等待健康接口空闲。输入图像预处理期间会标记取消并跳过后续语言推理，不承诺能立即打断底层图像编码调用。清缓存在忙碌时返回 HTTP 409，避免修改正在使用的状态。

本地新增逻辑保证工作线程停止、KV 清理后才释放推理并发名额。SSE 客户端断开也触发取消；非流式客户端需要停止任务时应显式调用中断接口。清缓存不删除客户端保存的 messages、不卸载模型，也不承诺擦除运行时分配内存的物理字节。

"""Small SSE text client. Private reasoning is discarded, never printed or saved."""
import argparse
import http.client
import json
import socket
import sys


class UnixConnection(http.client.HTTPConnection):
    def connect(self):
        self.sock=socket.socket(socket.AF_UNIX,socket.SOCK_STREAM)
        self.sock.settimeout(self.timeout)
        self.sock.connect(self.host)
        self.sock.settimeout(None)


def content_events(response):
    """Read bounded OpenAI-style SSE records, including multiline data fields."""
    data=[];size=0;received=0
    while True:
        line=response.readline(32769)
        if len(line)>32768:raise ValueError('SSE line exceeds limit')
        if not line:raise ValueError('Incomplete SSE response')
        if line.strip():
            if line.startswith(b'data:'):
                size+=len(line)
                if size>65536:raise ValueError('SSE event exceeds limit')
                data.append(line[5:].strip())
            continue
        if not data:continue
        raw=b'\n'.join(data);data=[];size=0
        if raw==b'[DONE]':return
        message=json.loads(raw)
        if message.get('error'):raise ValueError('Model service returned an error')
        for choice in message.get('choices',[]):
            delta=choice.get('delta') or {}
            if any(value is not None and not isinstance(value,str) for value in
                   (delta.get('content'),delta.get('reasoning_content'))):
                raise ValueError('Invalid text delta')
            # Count private output for resource limits without retaining it.
            received+=len(delta.get('content') or '')+len(delta.get('reasoning_content') or '')
            if received>32768:raise ValueError('Generation exceeds limit')
            value=delta.get('content')
            if value:
                if not isinstance(value,str):raise ValueError('Invalid content delta')
                yield value


def main():
    parser=argparse.ArgumentParser(description=__doc__)
    parser.add_argument('prompt')
    parser.add_argument('--unix-socket',default='/run/qwen3.5-2b/inference.sock')
    parser.add_argument('--no-thinking',action='store_true')
    args=parser.parse_args()
    payload=dict(model='Qwen3.5-2B',messages=[dict(role='user',content=args.prompt)],
                 enable_thinking=not args.no_thinking,stream=True,max_tokens=256,
                 temperature=0.6,top_p=0.95,top_k=20,presence_penalty=0.0,repeat_penalty=1.0)
    connection=UnixConnection(args.unix_socket,timeout=3)
    response=None
    try:
        connection.request('POST','/v1/chat/completions',json.dumps(payload).encode('utf-8'),{'Content-Type':'application/json'})
        response=connection.getresponse()
        if response.status!=200:raise RuntimeError('Model HTTP status '+str(response.status))
        for value in content_events(response):
            sys.stdout.write(value);sys.stdout.flush()
        print()
    finally:
        if response is not None:response.close()
        connection.close()  # Interrupting this client cancels this stream only.


if __name__=='__main__':
    try:main()
    except KeyboardInterrupt:raise SystemExit(130)
    except (OSError,ValueError,RuntimeError) as exc:
        print(str(exc),file=sys.stderr);raise SystemExit(1)
